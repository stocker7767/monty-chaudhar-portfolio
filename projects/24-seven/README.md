# 24 Seven Website Replica

A responsive replica of the 24 Seven website built using only HTML5 and CSS3.
This project was created to practice front-end development skills, responsive layouts, and modern UI design techniques.

## Features

* Responsive design
* Modern user interface
* Clean layout structure
* Navigation bar and sections
* Mobile-friendly design
* Pure HTML & CSS implementation

## Technologies Used

* HTML5
* CSS3

## Purpose

This project was developed for learning and practice purposes to improve front-end web development and website design skills.
